- 완성돼도 그림이 같은 자리·크기라 어색한 점프 없음 (확대 연출 제거)
- 아래쪽 조각 겹침 해결 (사과 위치/간격 조정)
- **데스크탑 겹침**도 해결: `#gc`가 `@media(min-width:769px)`에서 `max-width:768px` 세로 칼럼이 됨 → 화면 높이 비율 대신 **board(조각 크기) 기준 고정 간격 + 세로 중앙정렬**로 어떤 화면비에서도 안 겹치게

### 2. PNG 과일 지원 + 바나나 적용
- 과일마다 `WP_WORDS[...].img` 지정 시 SVG 대신 **PNG**로 조각·맞출자리 생성 (없으면 기존 SVG 유지 → 하나씩 교체 가능)
- 맞출 자리: PNG를 흐리게 + 그림 모양 마스크로 점선 칼선
- **PNG 알파 검사로 거의 빈(투명) 조각 자동 제외** (안 보이는 조각 = 못 맞추는 버그 방지). `wpPieceMask()`
- 바나나 → `assets/images/fruit_banana.png` 적용
- 관련 커밋: `93eff60`

### 3. 난이도 점진 증가
- 순서가 뒤일수록 조각이 많아짐: 1~2번째 4조각(2×2), 3~5번째 6조각(3×2), 6~8번째 9조각(3×3)
- 격자/절단선/흩어놓기 자리를 조각 수에 맞춰 자동 배치 (일반화)
- 난이도는 과일 이름이 아니라 `WP_ORDER` **위치 기준** (`WP_LEVELS`) → 과일 바꿔도 유지
- 관련 커밋: `a19c316`
