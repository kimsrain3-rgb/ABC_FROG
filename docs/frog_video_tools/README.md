# 개구리 반응 애니 변환 도구

마젠타 배경 mp4(Google Flow/Veo) → 투명 WebM 변환 파이프라인.

## 파일
- **convert_frog.py** — 배경 제거 + 투명 WebM 생성 (크롭 없음, 원본 비율 유지)
  - 배경색 자동 감지 / 거리+색조 이중 키잉(후광 제거) / 배경색 역산(테두리) / 얼룩 제거 / 핑퐁
- **normalize_frog.py** — 여러 클립의 개구리 몸 크기를 통일 (자르지 않고 여백만 채워 같은 캔버스로)
  - 배 너비 **85%값** 기준 (몸을 돌리는 클립도 정면 크기로 정확히 측정)

## 쓰는 법
1. Flow에서 클립을 뽑는다 → 프롬프트는 `../flow_prompt_template.md` (여백 넉넉히·정면·단색배경).
2. mp4를 `assets/frog/videos/`에 넣고, 두 스크립트 안 `CLIPS`/`jobs` 목록에 파일명 추가.
3. `python convert_frog.py` → `_frog_preview/`에 webm 생성 → 브라우저로 확인.
4. 크기 통일이 필요하면 `python normalize_frog.py`.
5. 확정되면 webm을 `assets/frog/videos/`로, 원본 mp4는 `assets/frog/videos/_source_mp4/`로.

## 겪은 교훈 (프롬프트/파라미터에 반영됨)
- 크롭하면 손 잘림 → 크롭 안 함 (게임은 개구리만 얹으니 비율 불필요)
- 워터마크("Veo")는 반투명 마젠타 → 배경 제거로 자동 소멸
- 입속 연어색이 배경과 가까움 → 키잉 강도(T1) 낮춰 입 구멍 방지
- 회전 동작(뒤돌아춤)은 핑퐁 불가 + 배 크기 측정에 중앙값 쓰면 과대확대 → 85%값 사용
- 모션 블러/원본 배경 얼룩은 후처리로 못 살림 → 재촬영 필요
