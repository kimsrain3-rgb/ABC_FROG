# Cooking game voice recordings

Put these nine MP3 files in this folder. Record the English line exactly as written.
The test game uses an English device voice until each recording is available.

| File | Spoken line |
| --- | --- |
| `cook_wash_tomato.mp3` | I want veggie soup! Wash the tomato. |
| `cook_peel_onion.mp3` | Peel the onion. |
| `cook_cut_carrot_twice.mp3` | Cut the carrot twice. |
| `cook_stir_three_times.mp3` | Stir the soup three times. |
| `cook_serve_soup.mp3` | Give me the soup, please. |
| `cook_one.mp3` | One. |
| `cook_two.mp3` | Two. |
| `cook_three.mp3` | Three. |
| `cook_yummy.mp3` | Yummy! Thank you! |
